# Simple Language

Правила ясного письма для Claude Code. Есть русский набор и английский.

[Read this in English](README.en.md)

## Боль

Claude по умолчанию пишет сложно. Предложения выходят длинными, специальные слова идут без пояснений, а мысли сжимаются в плотные тезисы. Понять такой текст можно, но приходится вчитываться и перечитывать.

## Решение

Этот набор правил учит Claude писать понятно. Он объясняет сложные вещи обычными словами и щедро форматирует текст, поэтому читатель схватывает смысл с первого раза.

Правила лежат в папке `~/.claude` и подключаются к Claude Code один раз. Дальше Claude пишет по ним сам, и просить его об этом в каждом разговоре не нужно.

Наборов два, русский и английский. Ставить можно оба сразу или только тот язык, на котором пишешь.

## Источники

Правила не придуманы с нуля. Они собраны из руководств, которыми пользуются государства и крупные компании.

- **Русские правила** сделаны по мотивам инфостиля Максима Ильяхова: сервис [Главред](https://glvrd.ru) и книга «Пиши, сокращай».
- **Английские правила** следуют [федеральным рекомендациям США по простому языку](https://www.plainlanguage.gov/guidelines/) и [руководству по стилю GOV.UK](https://www.gov.uk/guidance/style-guide).
- **Форматирование** для обоих языков опирается на руководства [Microsoft](https://learn.microsoft.com/en-us/style-guide/welcome/) и [Google](https://developers.google.com/style), а также на исследования [Nielsen Norman Group](https://www.nngroup.com/articles/how-users-read-on-the-web/) о том, как люди читают с экрана.

## Как это работает

Набор состоит из трёх частей, и каждая делает свою работу. Хук напоминает правила постоянно. Скил хранит их целиком и открывается под большую задачу. Проверщик читает уже написанный текст и ищет в нём нарушения.

### Хук напоминает правила в каждом сообщении

Хук (hook) — это маленькая программа, которую Claude Code запускает сам каждый раз, когда ты отправляешь сообщение. Она подкладывает Claude короткую выжимку правил размером примерно в полстраницы: девять главных пунктов и ни слова больше.

Смысл хука в постоянстве. Обычный разговор в чате — это как раз то место, где Claude забывает про простой язык, потому что ради короткого ответа он полный сборник правил не открывает. Напоминание же приходит всегда и почти ничего не стоит.

Файлы: `hooks/write-simply-reminder.sh` для русского и `hooks/write-simply-en.sh` для английского.

> Ставь только один хук, под тот язык, на котором пишешь. Если включить оба, Claude будет получать два напоминания сразу.

### Скил хранит полные правила

Скил (skill) — это папка с правилами, которую Claude открывает по необходимости. Внутри лежит файл `SKILL.md` с полным сводом: семь основных правил, приёмы починки тяжёлых фраз, примеры «плохо и хорошо» и словарь замен для сложных слов.

Claude открывает скил сам, когда берётся за большой текст. Ещё его можно позвать по имени, командой `/pishi-prosto` или `/plain-english`. Всё остальное время скил лежит на диске и места в разговоре не занимает.

Рядом со `SKILL.md` лежит папка `references/` с подробностями про форматирование: списки, таблицы, заголовки, картинки и текст ссылок. Claude подгружает её только под крупный документ, чтобы не таскать лишнее в каждый ответ.

Файлы: `skills/pishi-prosto/` и `skills/plain-english/`.

### Проверщик читает готовый текст

Проверщик — это программа, которая читает написанный файл и показывает места, где правила нарушены. Хук и скил влияют на Claude, пока он пишет, а проверщик работает уже с результатом. Запускают его руками, когда документ готов:

```bash
node ~/.claude/skills/pishi-prosto/scripts/prose-check.mjs "путь/к/файлу.md"
```

Русская проверка ловит образы, жаргон без пояснения и обрубленные фразы без сказуемого. Она же находит конструкцию «не X, а Y», проценты вместо долей, слишком длинные предложения, списки, которые были абзацами, и пустой текст ссылки вроде «здесь». Английская проверка ловит пассивный залог, формальные слова, спрятанные глаголы, длинные предложения и такой же пустой текст ссылки.

Чинить проверщик ничего не умеет и не всегда прав. Часть находок окажется ложной тревогой, и это нормально: решает всегда человек. Списки слов лежат рядом в файле `scripts/prose-rules.json`, и их можно пополнять руками. Поймал новый образ или непонятный термин, допиши строку туда, и проверка станет умнее.

Файлы: `skills/pishi-prosto/scripts/` и `skills/plain-english/scripts/`. Проверщик ставится вместе со своим скилом, отдельно копировать его не надо.

### Зачем нужны все три

Каждая часть закрывает то, чего не может другая. Полный сборник правил слишком большой, чтобы держать его открытым постоянно, поэтому Claude достаёт его только под крупную задачу. Чтобы правила не забывались в обычной переписке, короткое напоминание из хука приходит с каждым сообщением. А проверщик ловит то, что всё равно проскочило, потому что автор своих ошибок в тексте не видит.

Скилы работают в любом агенте на Claude Code. Хук — это возможность самого Claude Code, поэтому в другой программе он может не сработать.

## Установка

Проще всего попросить Claude. Склонируй репозиторий, открой папку в Claude Code и скажи: «установи эти правила письма себе». Claude прочитает файлы, скопирует нужный скил и хук в `~/.claude` и пропишет `settings.json`. Если нужен только один язык, так и скажи, какой.

```bash
git clone https://github.com/sailorstale/simple-language.git
```

Дальше идут подробности на случай, если ставишь без Claude или хочешь понять, что именно происходит. Обычному пользователю эти настройки трогать не нужно, Claude делает их за него.

### Установщик

Запусти скрипт. Он спросит язык и сам всё скопирует и подключит.

```bash
cd simple-language && ./install.sh
```

### Вручную по шагам

Первые два шага одинаковы для обоих скилов, третий нужен только для хука.

1. **Скопируй скилы** в папку скилов Claude:

```bash
cp -R skills/pishi-prosto skills/plain-english ~/.claude/skills/
```

2. **Скопируй хук своего языка** и сделай его исполняемым (только один, под свой язык):

```bash
# для русского:
cp hooks/write-simply-reminder.sh ~/.claude/hooks/ && chmod +x ~/.claude/hooks/write-simply-reminder.sh
# для английского:
cp hooks/write-simply-en.sh ~/.claude/hooks/ && chmod +x ~/.claude/hooks/write-simply-en.sh
```

3. **Подключи хук** в `~/.claude/settings.json`: добавь блок из [settings-snippet-ru.json](settings-snippet-ru.json) для русского или из [settings-snippet-en.json](settings-snippet-en.json) для английского.

> Если раздел `hooks` в файле уже есть, впиши запись `UserPromptSubmit` внутрь него. Второй раздел `hooks` заводить не нужно.

После этого перезапусти сессию Claude, чтобы он подхватил новый хук и увидел скилы.
