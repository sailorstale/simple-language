The file is a Russian onboarding guide for a new employee's first day.

PASS if all of the following hold:
- Steps are a numbered list, and each step is a complete sentence that names who does what.
- Paragraphs are short, two to four sentences, with headings that put the meaningful word first.
- There is no officialese: no «осуществить», «является», «данный», «в рамках», and no verbs hidden inside nouns like «проведение настройки».
- Technical terms such as repository or task tracker are explained in plain words the first time they appear.

FAIL if the guide is a wall of text, if steps are terse fragments without verbs, if it is written in officialese, or if it is not in Russian.
