# Словарь: сложное → простое

Частые технические слова и как их назвать по-человечески. Словарь общий, его можно пополнять под свой проект.

| Термин | По-человечески |
|--------|----------------|
| бэкенд | сервер: программа, которая хранит данные и отдаёт их приложению |
| база данных | склад данных, откуда приложение берёт информацию |
| API, эндпоинт | адрес, по которому приложение просит у сервера данные |
| схема данных | как устроены данные: какие поля есть у записи |
| миграция | изменение устройства базы |
| идемпотентный | «можно повторять без вреда» |
| деплой | выложить новую версию |
| рефакторинг | переборка кода без смены поведения |
