# Словарь: сложное → простое

Это полная версия правила 3, «Специальный термин: поясни, но не прячь всё». Словарь состоит из двух частей, и разделение важно для того, как им пользоваться.

- **Строгий список** держит слова, у которых простая замена верна почти в любом месте, поэтому программа ловит их дословно.
- **Список на усмотрение** держит слова с узким смыслом и с исключениями по месту, поэтому дословно их не ловят, а решают случай за случаем.

Помни правило 3: слово, которое читатель употребил сам, ему знакомо и замены не требует.

## Строгий список

Каждое слово здесь заменяется почти без потерь.

| Термин | По-человечески |
|--------|----------------|
| `бэкенд` | сервер: программа, которая хранит данные и отдаёт их приложению |
| `база данных` | склад данных, откуда приложение берёт информацию |
| `API, эндпоинт` | адрес, по которому приложение просит у сервера данные |
| `схема данных` | как устроены данные: какие поля есть у записи |
| `миграция` | изменение устройства базы |
| `идентификатор` | номер записи |
| `идемпотентный` | «можно повторять без вреда» |
| `деплой` | выложить новую версию |
| `рефакторинг` | переборка кода без смены поведения |
| `онтология` | устройство данных: из каких вещей они состоят |
| `таксономия` | словарь названий |
| `дистрибуция` | как продукт доходит до людей |
| `валидация` | проверка |
| `верификация` | сверка с источником |
| `коммуникация` | разговор, письмо, объявление |
| `имплементация` | выполнение, воплощение |
| `оптимизация` | ускорение или упрощение |
| `функционал` | возможности |
| `итерация` | заход, повтор |
| `эскалация` | передача старшему |
| `синхронизация` | сверка двух сторон |
| `консистентность` | согласованность данных |
| `легаси` | старый код, который держат ради работающих вещей |
| `фича` | возможность |
| `эдж-кейс` | редкий случай |
| `фидбек` | отклик, замечания |

## Список на усмотрение

Эти слова иногда стоят по делу, поэтому дословно их не ловят.

| Термин | Когда заменить | Когда оставить |
|--------|----------------|----------------|
| `интерфейс` | в разговоре о внешнем виде: «экран», «окно» | в разговоре о коде: у программы есть настоящий интерфейс |
| `сервис` | если речь о программе на сервере | если так называется услуга в договоре |
| `кейс` | в значении «случай» | в юридическом и медицинском смысле «дело», «история болезни» |
| `ресурс` | в значении «силы» и «время» | в техническом смысле: ресурс сервера, ресурс по адресу |
| `модель` | если речь о представлении предмета | если это модель нейросети или модель данных |
| `протокол` | если это порядок действий | если это сетевой протокол |
| `клиент` | в значении «покупатель» | в техническом смысле: клиентская программа |
| `платформа` | если речь о сайте или программе | если это в самом деле среда для чужих продуктов |

## Что делать с термином, которого тут нет

Правило 3 даёт три хода. Если у термина есть обычное слово и сам термин ничего не добавляет, пиши обычным словом. Если термин стоит знать, оставь его и коротко поясни при первом появлении. Если читатель уже показал, что знает слово, пользуйся им свободно.

Пополняй словарь под свою область: строгие пары идут ещё и в файл `scripts/prose-rules.json`, и тогда проверка начнёт их ловить.
